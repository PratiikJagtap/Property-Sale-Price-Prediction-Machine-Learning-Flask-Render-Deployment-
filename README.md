# 🏠 Property Sale Price Prediction (Machine Learning + Flask + Render Deployment)

This project predicts the **sale price of residential properties** using a trained **Machine Learning regression model**.  
It provides an **interactive web interface** built with **Flask** and is **deployed online via Render**, allowing users to input property details and instantly get price predictions.

### Live Demo: https://property-sale-price-prediction-machine.onrender.com/
---

## 🚀 Features
- Real-time property/house price prediction  
- Flask-based web interface for easy user input  
- Online deployment using **Render** (public access link)  
- End-to-end ML pipeline: **Data Cleaning → Model Training → Deployment**  
- Pre-trained model saved as `property-price-model.pkl`

---

## 🧠 Tech Stack
- **Python**
- **Flask**
- **Scikit-learn**
- **Pandas**, **NumPy**
- **HTML**, **CSS**
- **Render** (for online hosting)
